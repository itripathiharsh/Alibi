# 04 — API Specification

The **source of truth is the generated OpenAPI 3.1 document** (`backend/openapi.json`, regenerated by `make openapi`).
This document defines conventions and the endpoint catalogue; schemas live in Pydantic models and must match the descriptions here.

## 1. Conventions
- Base path `/api/v1`. JSON UTF-8. snake_case fields. Timestamps ISO-8601 with offset (server returns UTC `Z`). Dates `YYYY-MM-DD` interpreted in user tz.
- Auth: `Authorization: Bearer <access_token>` (except `/auth/login`, `/auth/refresh`, `/auth/setup`, `/auth/signup`, `/health/*`, `/s/*`).
- Device: `X-Device-Id: <uuid>` required on authenticated requests from apps (used by sync and audit).
- Idempotency: all `POST` creating resources accept client-supplied `id` (UUIDv7) **or** `Idempotency-Key` header; repeating returns the original result with `200` instead of `201`.
- Optimistic concurrency: `PATCH`/`DELETE` on syncable entities accept `If-Match: <version>`; mismatch → `409 version_conflict` with current entity in body.
- Pagination: `?limit=50&cursor=<opaque>` → `{ "items": [...], "next_cursor": "..." | null }`. Max limit 200.
- Filtering: explicit query params (no generic query language).
- Rate limits: auth 5/15 min failed; AI endpoints 30/min; share viewer 60/min/IP. `429` with `Retry-After`.

## 2. Error format (RFC 7807, `application/problem+json`)
```json
{ "type": "https://alibi.local/errors/validation_error", "title": "Validation failed", "status": 422,
  "code": "validation_error", "detail": "deadline_at must be in the future or null",
  "errors": [{"field": "deadline_at", "message": "..."}], "request_id": "..." }
```

## 3. Error code catalogue
| code | status | meaning |
|------|--------|---------|
| validation_error | 422 | Body/query invalid |
| unauthenticated | 401 | Missing/invalid/expired token |
| token_reused | 401 | Refresh token reuse; family revoked |
| forbidden | 403 | Valid auth, not allowed |
| not_found | 404 | Missing or not owned (never reveal existence) |
| version_conflict | 409 | If-Match mismatch |
| invalid_transition | 409 | Illegal status change |
| dependency_cycle | 409 | Would create cycle |
| proposal_stale | 409 | Schedule inputs changed since proposal |
| ai_unavailable | 503 | No provider reachable for the op (client must degrade) |
| ai_invalid_output | 502 | Provider returned unusable output after repair |
| rate_limited | 429 | |
| payload_too_large | 413 | Upload > limit |
| storage_quota_exceeded | 413 | Total stored files would exceed the configured quota (hosted default 250 MB, ADR-020) |
| share_expired / share_revoked | 410 | |

## 4. Endpoint catalogue

### 4.2 Auth (FR-AUTH)
| Method | Path | Body → Response |
|---|---|---|
| GET | /auth/setup-status | `{needs_setup: bool}` |
| POST | /auth/setup | `{email, password, display_name}` → 201 user; only when 0 users else 403 |
| POST | /auth/signup | `{email, password, display_name}` → 201 isolated user account; rate limited; duplicate email → 409 |
| POST | /auth/login | `{email, password, device:{id,name,platform}}` → `{access_token, refresh_token, expires_in, user}` (web: refresh in cookie) |
| POST | /auth/refresh | `{refresh_token}` or cookie → new pair (rotation) |
| POST | /auth/logout | revokes current device family |
| GET | /auth/me | user + settings |
| PATCH | /auth/me | display_name, timezone, settings (validated) |
| POST | /auth/change-password | `{current_password, new_password}` |
| GET | /auth/devices · DELETE /auth/devices/{id} | list / revoke |

Password policy: ≥ 12 chars, checked against a bundled top-10k common list; no composition rules.

### 4.3 Categories, projects, tags
CRUD: `GET/POST /categories`, `PATCH/DELETE /categories/{id}` (system: no delete → 409), same for `/projects`, `/tags`.
Category body: `{name, sharing_class, external_ai_allowed, color}`.

### 4.6 Evidence & uploads
`POST /tasks/{id}/evidence` (multipart file or JSON link/text; MIME allow-list: pdf, png, jpg, webp, docx, xlsx, txt, md, csv; ≤ 25 MB in local mode, **≤ 2 MB in hosted mode with a 250 MB total quota → 413 `payload_too_large` / `storage_quota_exceeded`**, ADR-020; limits come from config), `GET /evidence/{id}/download` (auth, `Content-Disposition: attachment`), `DELETE /evidence/{id}`.

### 4.7 Voice (FR-TASK-002, FR-AI-010)
`POST /voice/transcribe` multipart `audio` (m4a/aac/webm/wav ≤ 2 min / 10 MB), `language?` → `{transcript, language, duration_s, engine, confidence}`.
`POST /voice/capture` = transcribe + `/tasks/capture` in one call with `{id}`.
Hosted mode (ADR-020): these endpoints return 503 `ai_unavailable` unless external AI is enabled (then `engine=groq`); audio is never persisted. The Android client normally transcribes on-device and calls `/tasks/capture` directly with origin `voice`.

## 5. API acceptance criteria
- AC-API-1 Every endpoint has request/response Pydantic models, appears in OpenAPI with examples and error responses.
- AC-API-2 Schemathesis property-based run against OpenAPI: 0 server errors (5xx) and 0 schema violations.
- AC-API-3 Every authenticated endpoint returns 401 without token and 404 for another user's resource (ownership test generated per route).
- AC-API-4 Idempotency test: each create endpoint called twice with same id → one row, second call 200.
- AC-API-5 `If-Match` mismatch → 409 with current entity.
- AC-API-6 No endpoint returns `api_key`, `password_hash`, `token_hash` fields (response-model audit test).
- AC-API-7 Generated TS client compiles and CI fails when stale.
