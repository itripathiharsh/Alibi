# 03 — Database Schema

PostgreSQL 16 + pgvector. Migrations: Alembic only. Extensions: `vector`, `citext`, `pg_trgm`, `btree_gist`.

## 1. Conventions
- PK `id uuid` (UUIDv7). Syncable entities' IDs are generated by clients.
- All timestamps `timestamptz` UTC. Durations integer minutes.
- Enums as `text` + `CHECK` constraint (easier migrations than PG enums).
- Every owned row has `user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE` and every query filters on it (row ownership check in repository base class).
- **SyncableMixin** columns (on every table marked ⟳):

| Column | Type | Notes |
|--------|------|-------|
| `created_at` | timestamptz NOT NULL | client time accepted, clamped to server time +5 min |
| `updated_at` | timestamptz NOT NULL | server-assigned on write |
| `version` | integer NOT NULL DEFAULT 1 | incremented on every server write |
| `server_seq` | bigint NOT NULL | from global sequence `sync_seq`, set on every write (pull cursor) |
| `deleted_at` | timestamptz NULL | tombstone; rows physically purged after 30 days by job |
| `last_modified_device_id` | uuid NULL | FK devices |
| `field_versions` | jsonb NOT NULL DEFAULT '{}' | per-field version map for field-level merge (doc 11) |

Trigger `trg_sync_bump` sets `version`, `server_seq = nextval('sync_seq')`, `updated_at = now()` on INSERT/UPDATE.

- Append-only tables (✎) have a trigger rejecting UPDATE/DELETE (except purge by owner-initiated account deletion via `SET LOCAL alibi.allow_purge = on`).

## 2. Entity-relationship overview
```
users ─┬─ devices ── refresh_tokens
       ├─ organizations ── organization_memberships ── organization_invites
       │                                    └─ professional activity (read through consent scope)
       ├─ workspaces ─┬─ categories ── projects
       │              └─ tags
       ├─ tasks ─┬─ subtasks / task_tags / task_dependencies / time_entries / evidence
       │         ├─ task_events ✎ / task_predictions / ai_extractions
       │         └─ recurrence_rules (template)
       ├─ calendar_events      ├─ work_logs      ├─ notes ── embeddings
       ├─ behavior_observations ✎ ── learned_patterns ── memory_profiles
       ├─ schedule_recommendations
       ├─ ai_provider_settings / ai_usage_logs
       ├─ reports ── report_shares ── report_share_access_log ✎
       ├─ sync_operations / notifications / audit_log ✎ / jobs / chat_threads ── chat_messages
```

## 3. Tables

### 3.1 Identity
**users**: `id`, `email citext UNIQUE NOT NULL`, `password_hash text NOT NULL`, `display_name text`, `timezone text NOT NULL DEFAULT 'Asia/Kolkata'`,
`settings jsonb NOT NULL DEFAULT '{}'` (validated by `UserSettings` Pydantic: working_hours per weekday, day_start, min_block_min=30,
max_daily_focus_min=480, reminder_lead_min, quiet_hours, auto_classify_threshold=0.85, ai_external_enabled=false, ask_for_deadlines=false),
`created_at`, `updated_at`, `password_changed_at`.

**devices**: `id`, `user_id`, `name`, `platform CHECK in ('android','web')`, `app_version`, `last_seen_at`, `last_pull_seq bigint DEFAULT 0`, `revoked_at`, `created_at`.

**refresh_tokens**: `id`, `user_id`, `device_id`, `family_id uuid`, `token_hash bytea UNIQUE` (SHA-256), `expires_at`, `used_at`, `revoked_at`, `created_at`. Index `(family_id)`.

**organizations**: `id uuid`, `name`, `slug`, `owner_user_id`, `created_at`, `updated_at`, `status CHECK in ('active','suspended','deleted')`. Owner is an ALIBI account; organization membership does not change ownership of personal records.

**organization_memberships**: `id uuid`, `organization_id`, `user_id`, `role CHECK in ('owner','team_lead','member')`, `status CHECK in ('active','left','revoked')`, `professional_sharing_consent bool`, `consent_version text NULL`, `consented_at timestamptz NULL`, `revoked_at timestamptz NULL`, `created_at`. Unique `(organization_id,user_id)`; active member access requires consent=true and non-null `consented_at`. Owner/lead access is role-based and never grants data-owner rights.

**organization_invites**: `id uuid`, `organization_id`, `created_by_user_id`, `role CHECK in ('team_lead','member')`, `token_hash bytea UNIQUE` (raw token shown once), `expires_at`, `accepted_by_user_id NULL`, `accepted_at NULL`, `revoked_at NULL`, `created_at`. Index `(organization_id, created_at)`. Invitation links are revocable, expire, and contain no member data.

### 3.2 Organization
**workspaces** ⟳: `id`, `user_id`, `name`, `is_default bool`. Each new account receives one default workspace; account data remains isolated by `user_id`.

**categories** ⟳: `id`, `user_id`, `workspace_id`, `name`, `slug`, `is_system bool`, `sharing_class CHECK in ('professional','personal','academic','learning')`,
`external_ai_allowed bool NOT NULL` (default false for personal, true otherwise — still subject to global switch), `color`, `position`.
UNIQUE `(user_id, slug) WHERE deleted_at IS NULL`. System categories cannot be deleted (only renamed).

**projects** ⟳: `id`, `user_id`, `workspace_id`, `category_id NULL`, `name`, `description`, `status CHECK in ('active','paused','done','archived')`, `color`.

**tags** ⟳: `id`, `user_id`, `name`, UNIQUE `(user_id, lower(name))`. **task_tags** ⟳: `task_id`, `tag_id` (PK both) + sync columns.

### 3.3 Tasks
**tasks** ⟳
| Column | Type | Notes |
|--------|------|-------|
| id, user_id, workspace_id | uuid | |
| title | text NOT NULL | 1–300 chars |
| description | text NULL | ≤ 20k chars |
| raw_input | text NULL | original capture text/transcript |
| category_id / project_id | uuid NULL | FK |
| status | text NOT NULL DEFAULT 'pending' | pending/in_progress/completed/cancelled |
| priority | smallint NULL | 1 (urgent) – 4 (low); NULL = unset |
| deadline_at | timestamptz NULL | |
| deadline_kind | text NULL | hard/soft |
| deadline_source | text NULL | user/extraction/recurrence |
| estimate_user_min / estimate_ai_min | int NULL | |
| estimate_final_min | int NULL | the one used for planning (user wins over AI) |
| actual_min | int NOT NULL DEFAULT 0 | cached sum of time_entries (maintained in service; verified by nightly job) |
| started_at / completed_at / cancelled_at | timestamptz NULL | |
| origin | text NOT NULL | manual/voice/ai_recommendation/meeting/external_assignment/recurring |
| origin_ref | text NULL | e.g. meeting name, assigner |
| recurrence_rule_id | uuid NULL | FK recurrence_rules |
| recurrence_instance_date | date NULL | UNIQUE (recurrence_rule_id, recurrence_instance_date) |
| reschedule_count | int NOT NULL DEFAULT 0 | |
| parse_status | text NOT NULL DEFAULT 'none' | none/pending/proposed/accepted/failed |
| completion_note | text NULL | |
Indexes: `(user_id, status, deadline_at)`, `(user_id, completed_at)`, `(user_id, server_seq)`, GIN trigram on `title`.
CHECK: `completed_at IS NOT NULL` iff status='completed'; `estimate_* > 0 AND <= 10080`.

**subtasks** ⟳: `id`, `user_id`, `task_id`, `title`, `is_done`, `position int`, `completed_at`.
**task_dependencies** ⟳: `task_id`, `depends_on_task_id`, CHECK not self; cycle prevention in service (DFS) + test.
**recurrence_rules** ⟳: `id`, `user_id`, `template jsonb` (title, category, project, estimate, priority, deadline_offset), `rrule text` (RFC 5545), `dtstart`, `until NULL`, `active bool`, `generated_until date`, `source` (user/learned_routine).

**task_events** ✎: `id`, `user_id`, `task_id`, `event_type text` (created, field_changed, status_changed, rescheduled, estimate_changed, priority_changed,
time_logged, subtask_changed, evidence_added, prediction_feedback, deleted, restored), `changes jsonb` ({field: [old,new]}), `reason text NULL`,
`actor CHECK in ('user','ai','system','sync')`, `device_id`, `occurred_at` (client time), `recorded_at` (server). Index `(task_id, occurred_at)`.

**time_entries** ⟳: `id`, `user_id`, `task_id`, `started_at`, `ended_at NULL` (running timer), `duration_min int NULL` (computed on stop; or manual),
`source CHECK in ('timer','manual','pomodoro')`, `note`. Constraint: at most one running timer per user (partial unique index on `user_id WHERE ended_at IS NULL AND deleted_at IS NULL`).
CHECK `ended_at > started_at`, `duration_min BETWEEN 1 AND 1440`.

**evidence** ⟳: `id`, `user_id`, `task_id`, `kind CHECK in ('file','link','text')`, `title`, `url`, `text`, `storage_key`, `mime`, `size_bytes`, `sha256`, `is_deliverable bool`.

**ai_extractions**: `id`, `user_id`, `task_id`, `input_text`, `rules_result jsonb`, `llm_result jsonb NULL`, `final_proposal jsonb` (field → {value, confidence, evidence_span, source}),
`clarification jsonb NULL`, `provider`, `model`, `prompt_version`, `latency_ms`, `status`, `created_at`, `decided_at`, `user_decision jsonb`.

### 3.4 Calendar & logs
**calendar_events** ⟳: `id`, `user_id`, `kind CHECK in ('fixed_event','work_block')`, `title`, `start_at`, `end_at`, `all_day bool`,
`task_id NULL` (required for work_block), `rrule NULL`, `rrule_exdates timestamptz[]`, `recurrence_parent_id NULL` (overridden instance),
`locked bool` (true for fixed_event), `source CHECK in ('user','ai_accepted','import')`, `schedule_recommendation_id NULL`, `location`, `notes`.
Exclusion constraint optional for non-recurring work blocks: `EXCLUDE USING gist (user_id WITH =, tstzrange(start_at,end_at) WITH &&) WHERE (kind='work_block' AND deleted_at IS NULL)` — overlap between blocks is not allowed; overlap with fixed events detected in service (warn, user may allow).

**work_logs** ⟳: `id`, `user_id`, `log_date date`, `content text`, `category_id NULL`, `project_id NULL`, `task_ids uuid[]`. UNIQUE not required (multiple entries/day).

### 3.5 Knowledge
**notes** ⟳ (Knowledge Vault item): `id`, `user_id`, `source_type CHECK in ('task_description','completion_note','work_log','project_note','meeting_note','document','decision','deliverable','manual')`,
`source_id uuid NULL`, `title`, `body text`, `occurred_on date`, `category_id NULL`, `project_id NULL`, `task_id NULL`,
`privacy_class` (copied from category sharing_class; manual override allowed), `storage_key NULL`, `content_hash`, `embed_status CHECK in ('pending','done','failed','skipped')`.
UNIQUE `(source_type, source_id)` for auto-ingested items (idempotent ingestion).

**embeddings**: `id`, `user_id`, `note_id`, `chunk_index`, `content text`, `embedding vector(384)`, `model text`, `content_hash`,
`meta jsonb` (occurred_on, category_id, project_id, privacy_class, source_type), `created_at`.
Index: HNSW `embedding vector_cosine_ops` (m=16, ef_construction=64); btree `(user_id, (meta->>'occurred_on'))`.
Changing embedding model → new rows with new `model`, old rows deleted after backfill (job `reembed_all`).

### 3.6 Learning
**behavior_observations** ✎: `id`, `user_id`, `task_id NULL`, `observation_type` (doc 07 §2 list), `features jsonb`, `observed_at`, `recorded_at`.
Index `(user_id, observation_type, observed_at)`.

**learned_patterns** ⟳: `id`, `user_id`, `pattern_type CHECK in ('routine','duration','work_period','postponement','session_length','interruption','category_distribution')`,
`key text` (e.g. cluster id or category slug), `value jsonb`, `sample_count int`, `support jsonb` (observation ids, ≤ 200 most recent), `confidence numeric(4,3)`,
`status CHECK in ('candidate','active','confirmed','dismissed','stale')`, `first_observed_at`, `last_observed_at`, `updated_at`, `algorithm_version`.
UNIQUE `(user_id, pattern_type, key)`.

**memory_profiles**: `id`, `user_id`, `version int`, `profile jsonb` (compiled view of active patterns + maturity levels), `computed_at`. Keep last 30 versions.

**task_predictions**: `id`, `user_id`, `task_id`, `prediction_type CHECK in ('category','project','duration','priority','dependency')`, `predicted jsonb`,
`interval jsonb NULL` (p10/p50/p90 for duration), `confidence numeric(4,3)`, `maturity_level smallint`, `model_name`, `model_version`,
`features jsonb`, `outcome CHECK in ('pending','accepted','corrected','rejected','ignored')`, `actual jsonb NULL`, `error numeric NULL`, `created_at`, `resolved_at`.

**ml_models**: `id`, `user_id`, `model_type`, `version`, `trained_at`, `train_rows int`, `metrics jsonb`, `artifact bytea` (joblib, ≤ 5 MB) , `active bool`.

### 3.7 Scheduling
**schedule_recommendations**: `id`, `user_id`, `scope CHECK in ('task','day','horizon')`, `horizon_start`, `horizon_end`, `status CHECK in ('proposed','accepted','partially_accepted','rejected','expired','superseded','infeasible')`,
`input_snapshot jsonb`, `input_hash text`, `proposals jsonb` ([{task_id, start_at, end_at, reasons[]}]), `displacements jsonb` (existing blocks it wants to move, each needs approval),
`unscheduled jsonb` ([{task_id, reason}]), `solver_status`, `objective jsonb` (component breakdown), `solve_ms`, `explanation_text NULL`, `created_at`, `decided_at`, `decision jsonb`.

### 3.8 AI
**ai_provider_settings**: `id`, `user_id`, `provider CHECK in ('ollama','nvidia','gemini','groq')`, `enabled bool`, `api_key_encrypted bytea NULL`, `key_last4 text NULL`,
`base_url`, `models jsonb` (available + selected per capability), `fallback_rank int`, `last_test_at`, `last_test_status`, `routing_overrides jsonb`.
UNIQUE `(user_id, provider)`.
**ai_usage_logs**: `id`, `user_id`, `provider`, `model`, `operation`, `input_tokens`, `output_tokens`, `latency_ms`, `status` (ok/timeout/rate_limited/invalid_output/error),
`error_code`, `estimated_cost_usd numeric(10,6)`, `fallback_from NULL`, `created_at`. No prompt or completion content stored.
Retention 180 days.

**chat_threads** / **chat_messages**: `thread(id,user_id,title,created_at,deleted_at)`, `message(id,thread_id,role,content,sources jsonb,tool_calls jsonb,provider,model,created_at)`.

### 3.9 Reports & sharing
**reports**: `id`, `user_id`, `report_type CHECK in ('eod','weekly','monthly','custom')`, `period_start date`, `period_end date`, `scope jsonb` (included sharing classes),
`facts jsonb` (frozen), `facts_hash`, `narrative text NULL`, `narrative_status`, `narrative_model`, `status CHECK in ('generating','ready','failed')`,
`files jsonb` ({pdf: storage_key, xlsx:…, csv:…}), `generated_at`.
**report_shares**: `id`, `user_id`, `report_id`, `token_hash bytea UNIQUE`, `token_prefix char(6)` (display only), `recipient_label`, `scope jsonb`,
`shared_facts jsonb` (scope-filtered snapshot built at share time), `allow_download bool`, `expires_at NOT NULL`, `revoked_at`, `created_at`, `last_accessed_at`, `access_count`.
**report_share_access_log** ✎: `id`, `share_id`, `accessed_at`, `ip_hash`, `user_agent_hash`, `outcome` (ok/expired/revoked/not_found).

### 3.10 Platform
**sync_operations**: `op_id uuid PK` (client-generated), `user_id`, `device_id`, `entity_type`, `entity_id`, `op_type CHECK in ('create','update','delete','command')`,
`base_version int NULL`, `payload jsonb`, `client_ts`, `received_at`, `result CHECK in ('applied','merged','conflict','rejected','duplicate')`, `result_detail jsonb`, `new_version int`.
Retention 90 days. Duplicate `op_id` → return stored result (idempotency).
**sync_conflicts** ⟳: `id`, `user_id`, `entity_type`, `entity_id`, `field`, `local_value jsonb`, `server_value jsonb`, `op_id`, `status CHECK in ('open','resolved_local','resolved_server','resolved_custom')`, `resolved_at`.
**notifications** ⟳: `id`, `user_id`, `kind` (task_reminder, deadline_soon, block_start, daily_plan, sync_conflict, proposal_ready), `task_id NULL`, `event_id NULL`, `fire_at`, `title`, `body`, `status` (scheduled/delivered/dismissed/cancelled), `delivered_at`.
**audit_log** ✎: `id`, `user_id NULL`, `action` (login_ok, login_failed, token_reuse_detected, password_changed, device_revoked, api_key_set, api_key_deleted, share_created, share_revoked, export_created, backup_restored, data_deleted, ai_external_toggled), `ip_hash`, `detail jsonb` (no secrets), `created_at`.
**jobs**: `id bigserial`, `kind`, `payload jsonb`, `status CHECK in ('queued','running','done','failed','dead')`, `attempts`, `max_attempts DEFAULT 5`, `run_after`, `locked_by`, `locked_at`, `last_error`, `dedupe_key text NULL UNIQUE WHERE status IN ('queued','running')`, `created_at`, `finished_at`.

## 5. Schema acceptance criteria
- AC-DB-1 `alembic upgrade head` on empty DB and `downgrade base` then `upgrade head` again succeed (CI).
- AC-DB-2 Migration test: each revision upgraded with representative rows present, data preserved.
- AC-DB-3 Append-only triggers: UPDATE/DELETE on `task_events`, `behavior_observations`, `audit_log` raise.
- AC-DB-4 `server_seq` strictly increases across concurrent writes (concurrency test, 20 parallel writers).
- AC-DB-5 Ownership: repository tests prove one account cannot read/write another account's rows.
- AC-DB-6 Running-timer uniqueness and work-block exclusion constraints reject violations.
- AC-DB-7 `tasks.actual_min` equals SUM(time_entries) for all tasks (nightly verifier job + test).
- AC-DB-8 `docs/03` updated in the same commit as any migration (CI check: migration file changed ⇒ this doc changed).
