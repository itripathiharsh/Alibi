- Acceptance criteria:
  - AC-M13-1 Six requested destinations render in the requested order with a clear selected state and accessible labels.
  - AC-M13-2 Home, task lists, calendar, and insights continue using existing authenticated API data and existing actions.
  - AC-M13-3 Vault reads notes/search results from `/api/v1/vault/*`; empty, loading, and error states are visible; the existing grounded assistant remains reachable.
  - AC-M13-4 Profile uses `/api/v1/auth/me`, analytics summary, and learning profile where available; no sample metrics or personal records are hard-coded.

  - AC-M13-6 Light mobile surfaces, typography, iconography, spacing, and shared card treatment align with the supplied references; controls meet 48 dp targets and reduced motion/contrast guidance.
  - AC-M13-7 Settings/logout and login remain navigable and visually consistent; no new dependency, sync-envelope/conflict-rule, or provider changes. The additive task-note link schema/API is covered by migration and ownership tests.
  - AC-M13-8 Any visitor can create an isolated account from web or Android; duplicate email is handled safely; signup creates only that account's default workspace and categories; protected data remains scoped to the authenticated user.
- AC-M13-9 Owner can create organizations and role-scoped, expiring invitation links.
- AC-M13-10 Invite acceptance requires explicit, versioned professional-only sharing consent; member can revoke/leave.
- AC-M13-11 Organization views require active role membership and use live SQL data filtered to consented professional records.
- AC-M13-12 No private or non-professional record details are disclosed; productivity scores are recomputed from professional-only tasks.
- AC-M13-13 Public landing pages remain unchanged; authenticated web routes show the organization portal and block individual-only accounts.
  - AC-M13-18 Morning kickoff suggestions come from account-owned SQL data, remain proposals until confirmed, and appear at most once per local morning from 06:00–10:00 in the account timezone.
  - AC-M13-19 Optional end-of-day review uses SQL counts and changes tasks only after an explicit action; next-workday moves increment reschedule count and add a task event.
  - AC-M13-20 Android focus notification shows elapsed/remaining timer state with pause/complete actions and hides task titles by default; widget and Quick Settings entry points open typed/voice capture.
  - AC-M13-21 Focus protection requires opt-in, uses the user's observed focus hour and working hours, skips existing calendar conflicts, and never moves existing events.
  - AC-M13-22 Vault/task links are owner-scoped, visible from either screen, and append a factual completion log to the linked note.
  - AC-M13-23 Weekly retrospective counts come from SQL, reflection is saved as a personal Vault note, and batch actions/haptics/offline ambient audio introduce no sample content or external media dependency.

Organization reporting adds cross-account access and consent risks; keep M13 in progress until automated isolation tests and manual review pass.
